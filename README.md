# Calculadora Básica em Python

Este é um projeto simples de uma **calculadora básica** desenvolvida em Python. A aplicação permite realizar operações como **soma**, **subtração**, **multiplicação** e **divisão**. O projeto foi desenvolvido com o objetivo de praticar os conceitos básicos de programação, como funções e manipulação de entradas e saídas de dados.

## Funcionalidades:
- Soma
- Subtração
- Multiplicação
- Divisão

## Tecnologias Utilizadas:
- Python 3.x

## Como rodar o projeto:
1. Clone o repositório:
   `git clone https://github.com/seunome/calculadora-python.git`
2. Navegue até a pasta do projeto.
3. Execute o arquivo `Calculadora básica.py` no Python.
